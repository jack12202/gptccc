# 支付卡来源渠道与天空格式

首页和完整支付卡池增加独立的“来源渠道”列，与“适用协议”分别展示。

- 手动导入时，在“来源渠道”必选“天空”“ZZS / 吱吱鼠”，选择“其他渠道…”后可填写自定义渠道。
- “zzs”“zzshu”“吱吱鼠”统一显示为“ZZS / 吱吱鼠”，“天空卡台”统一为“天空”。
- 已有手动卡在首页或完整卡池的“来源渠道”下拉框直接修改，选择后立即保存，不需要进入管理或重新导入。
- 嗨付同步卡的来源固定为“嗨付”。
- 来源标注不改变充值协议、次数、冻结、暂停状态或历史订单。旧卡的来源是“手动导入”等未分类值时，备注精确等于“天空”“天空卡台”或 ZZS 的别名会用于渠道显示；其他备注不作推断，显示“未标注 · 选择渠道”。显示兼容不改写原始数据，选择渠道后显式保存。已有明确来源优先于备注。

新增天空复制格式：`卡号:…;CVV…;有效期:MM/YY`。支持 CVV 后有或无冒号、中英文冒号和分号、字段前后的空格及字段换序。仍按每行一张解析，校验卡号、CVV 与有效期；同一卡号跨格式仍跳过重复导入。原逗号和 ZZS 空格格式继续支持。

预览只返回尾号；导入后支付资料继续使用原有加密保存流程。自动测试和线上只读预览使用虚构资料，不导入用户提供的真实支付卡。
