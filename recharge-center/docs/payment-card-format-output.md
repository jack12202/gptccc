# 录入区的 ZZS 标准格式输出

首页和完整支付卡池的录入区域新增“ZZS 一次粘贴格式”。

1. 每行粘贴一张支付卡。支持原有逗号、ZZS 空格和天空字段格式，也支持“卡号----MM/YY----CVV----”（末尾分隔符可省略）。
2. 输入时立即生成标准化结果，不需要先预览或导入。
3. 点击每行“复制”或“复制全部”，得到“卡号----MM/YY----CVV----”。批量复制按行换行，只包含识别通过且不重复的卡。CVV 的前导零保留。
4. 将单张结果粘贴到 ZZS 前端的卡号框，按其整段粘贴功能填写卡片信息。

错误、过期和重复行单独提示，不提供其复制按钮。修改输入会重新生成结果；清空输入、成功导入会清除输出。

整理和复制在当前浏览器完成，不依赖新增明文 API，不读取已保存支付卡。导入仍使用既有管理员认证、脱敏预览、重复检测和加密保存流程。客户端和服务端复用同一解析模块，避免整理通过但导入失败。

原有来源渠道、总次数、启用状态和充值协议逻辑保持不变。测试与浏览器验证仅使用虚构支付卡资料。
