# 支付卡次数快捷加减

2026-11-02：本地验证完成，用户于 2026-11-02 授权与简化订单处理、居中小浮窗一并推送上线，部署结果见发布回执。

支付卡池和工作台支付卡列表增加“−1 次”，与“＋1 次”“增加…”并列。单击直接减少当前可用次数，不弹出修改总次数或备注的表单。当前可用为 0 时按钮禁用；同张卡的加减请求进行中暂时禁用按钮，防止误连点。

后端调整总容量，使当前可用次数减少 1，已用、冻结、备注、启用与暂停状态均不改变。不能减少已用、冻结或正在处理的预留次数，不能出现负数。手工卡和嗨付共享卡池共用相同逻辑。

调整记录使用持久化请求标识，网络重试不会重复减少，服务重启后仍有效；保留管理员调整审计。原只增加接口保持兼容。

验证：125 项回归测试通过。Chrome 使用虚构卡片验证两个入口的加减、减少至 0 后禁用、已用/冻结不变以及手机宽度操作，无页面脚本错误。
