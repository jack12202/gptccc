# ZZS 提交排队（2026-10-10）

有效卡密与账号资料通过校验后，缺支付卡、通道并发已满、通道暂未启用、上游预检异常及支付资料准备失败，保存为后台待人工处理订单，用户查询返回 processing 和“已提交，排队处理中，请勿重复提交”。不将排队标为充值成功。卡密绑定首次提交账号、保持占用，原始 Session 加密保存；重复提交返回原订单。

后台复用待确认订单的人工处理入口。人工操作充值后核实到账再确认成功；确认未支付沿用后台现有处理入口。上游明确拒绝创建订单仍沿用失败流程。无效卡密、账号不匹配、无效 Session 等校验错误仍返回具体提示；数据库或加密保存不可用时不能假装已接单。

无支付卡的订单使用不可选择的禁用占位记录兼容既有外键，支付卡列表隐藏该记录。排队不自动补卡重发，由运营人工处理，避免重复扣费。
