# 已保存支付卡复制标准格式

首页“正在使用的支付卡”和完整支付卡池的每行增加“复制标准格式”。点击后复制“卡号----MM/YY----CVV----”，包含末尾分隔符，保留 CVV 前导零。列表继续只显示尾号。

手动导入卡按需解密已保存资料；嗨付同步卡通过已有上游敏感详情接口按需读取。资料无法读取、已过期、尾号不匹配或卡片已移出时返回提示，不返回错误详情或部分资料。手动卡同时校验卡号指纹，防止复制到别的卡片资料。

接口：管理员 POST /api/admin/payment-cards/{manual|h}/{id}/copy-standard，使用现有登录会话及 CSRF 验证，响应禁止缓存。操作审计只记录卡片 ID 与管理员标识，不记录卡号、CVV 或完整输出。

复制不提交充值、不占用卡片、不修改次数、冻结、启用状态或订单。读取结果只用于当前复制操作，不加入卡池列表、工作台快照或浏览器持久存储。

验证使用虚构支付卡；线上检查只请求不存在的测试 ID，不读取用户真实卡片资料。
