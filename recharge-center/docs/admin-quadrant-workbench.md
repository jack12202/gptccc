# 四象限工作台与今日经营概览

2026-11-02：按用户确认的四象限原型实现，本地验证完成，用户于 2026-11-02 授权先推送四象限工作台，部署结果见发布回执。

## 界面

- 顶部四项指标：今日充值成功、今日核销卡密、今日新提交、当前待处理。
- 中间两行两列：需要处理、支付卡、卡密库存、充值订单。始终保留四个框，详情在整个网格下方展开。
- 初始详情收起；点击框展开，再次点击收起。切换框只展示对应一处详情。收起按钮将焦点还给入口。
- 通道与设置放到顶部，使用同一个详情区；保留协议设置及 ZZS 查询深链接。
- 生成卡密、录入支付卡自动展开相应区域和表单。刷新统计不会重置已展开区域、填写内容或筛选。
- 手机仍保留两列功能框，顶部统计调整为两列。表格在独立容器内横向查看。

## 统计与明细

- 日期以北京时间自然日为准。
- 今日成功按完成时间统计，支持昨天提交、今天完成的订单；自动与人工成功都计入，失败、冻结、自动归档不计入。
- 今日核销按客户卡密实际核销时间去重。停用或归档不抹去已经发生的核销。原生旧 ZZS 卡密也可查询核销明细。
- 没有真实成功时间的历史记录不根据提交时间或最近查单时间猜测，页面提示其未计入；旧 ZZS 记录同步也不会把今日同步时间伪造成核销时间。
- 今日新提交按同账号、同卡密的最新一次提交计数，包括今日已本地结案的提交；可只读回看历史和复制 JSON。
- 点击四项数字会展开并筛选同一批明细。今日核销视图只展示核销记录，不提供库存批量修改和无效的旧卡密链接操作。
- 原有重新导入卡片、24 小时自动归档和原冻结/占用/次数保留规则不变。
